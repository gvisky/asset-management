The website runs in the cloud and can't reach the office network, so a small collector program on an always-on PC in each office checks the router, switches, servers and web apps every minute and sends the results here.

  1. Turn on SNMP (read-only) on the router: System Maintenance → SNMP, set your own Get Community and the collector PC as Manager Host.
  2. Click ➕ Add collector (IT admin) and copy the key.
  3. On the office PC: install Node.js LTS, copy the collector folder from the project, put the key in config.json, run npm install and node collector.js --once, then install-windows.ps1. Full steps: collector/README.md.
